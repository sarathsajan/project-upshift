standard way is very complicated way to authenticate and authorise
1. we have to first generate a AUTH CODE - via upstox login ui
    > send request to api
    > redirect to upstox login ui
    > complete login manually
    > redirect and recieve your AUTH CODE at redirect_uri
2. then use this AUTH CODE to generate the access token
3. use this access token to call subsequent api calls, expires at 03:00 AM

this is very unintuitive and too complex for simple apps so they have an api 
developers page where you generate access token manually one time that can be 
used for roughly 15 days, then repeat again after expiry.

so basically we can skip the whole process of programmatic logging in and 
generating access token which is then supplied to subsequent api calls. instead 
all we have to do is every day login to developer dashboard, generate the 
access token then update it in the env file.
